# Client demo previews

Concept homepages I build for small businesses that have no website or a broken one, so they can see what a simple site and chat assistant would look like before deciding anything.

Each page is clearly marked as a demo, is not the business's official website, and is hidden from search engines. Demos are removed when a business asks or if they aren't taken up.
